# เลขเด็ดตามสถิติ

เว็บจัดอันดับเลขหวยรัฐบาลงวดถัดไปจากผลย้อนหลังตั้งแต่ปี 2553 พร้อมผลทดสอบย้อนหลังของทุกสูตรเทียบกับการเดามั่ว

- `index.html` หน้าเว็บ คำนวณทั้งหมดในเบราว์เซอร์
- `data.json` ผลรางวัลทุกงวด
- `scripts/update_data.py` ดึงผลงวดใหม่มาเพิ่มใน `data.json`
- `.github/workflows/update-data.yml` รันสคริปต์อัตโนมัติหลังวันหวยออก และ commit ผลใหม่เอง

หวยออกแบบสุ่ม ไม่มีสูตรไหนรับประกันว่าถูก ใช้เพื่อความสนุกเท่านั้น
